# oneancillaground
Ground-State Preparation with a Single Ancilla via Lindblad Dynamics

This folder contains the implementation in

[1] Y. Zhan, Z. Ding, J. Huhn, J. Gray, J. Preskill, G. Chan, L. Lin, Rapid quantum ground state preparation via dissipative dynamics, arXiv:2503.15827 (2025).
https://arxiv.org/abs/2503.15827

QuasiFree.ipynb is the implementation of dissipative quasi-free dynamics, including TFIM and SPT Hamiltonian with boundary dissipation.

TensorNetwork-TFIM.py and TensorNetwork-Heisenberg.py are the implementation of tensor network simulation of bulk dissipative dynamics of TFIM and Heisenberg model. Require GPU to run.
